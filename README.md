# VenueGo



球館預約與訂單管理系統。



## 專案介紹



VenueGo 是以 ASP.NET Core MVC 開發的球館預約後台管理系統，

提供管理員進行球館、場地、會員、預約、訂單、付款與退款等資料管理。



## 技術架構



- ASP.NET Core MVC

- .NET 10

- Entity Framework Core

- SQL Server

- Bootstrap 5

- jQuery

- Git

- GitHub



## 開發環境



- Visual Studio

- .NET 10 SDK

- SQL Server

- SQL Server Management Studio
